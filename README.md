# PingPong-Game

A simple, browser-based Ping Pong (Pong) game built with HTML, CSS, and JavaScript.

This project has been enhanced with frame-rate independent movement, touch controls, difficulty settings, and persistence (best score + audio/difficulty saved in localStorage). A start/serve overlay and improved audio handling (Web Audio API) were also added.

## Demo

Open `index.html` in a modern desktop or mobile browser to play locally. To host on GitHub Pages, enable Pages in repository Settings and set the source to the `main` branch (or to the `docs/` folder if you prefer).
https://abhishek6002.github.io/PingPong-Game/
## What's new

- Frame-rate independent physics (movement uses delta time)
- Touch controls for mobile
- Difficulty levels (Easy / Medium / Hard)
- Best-score saved in localStorage
- Audio setting persisted
- Start / Serve overlay screen
- Responsive canvas with high-DPI support

## How to run locally

1. Clone the repository

   git clone https://github.com/Abhishek6002/PingPong-Game.git

2. Open `index.html` in your browser, or serve the folder with a local HTTP server (recommended for some browsers):

   python -m http.server 8000
   Open http://localhost:8000 in your browser.
